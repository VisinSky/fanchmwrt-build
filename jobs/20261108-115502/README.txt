FanchmWrt Builder 构建套件
==========================
在 Ubuntu 22.04 上安装依赖后执行： bash run.sh
deps: build-essential clang flex bison gawk gcc-multilib g++-multilib gettext
      git libncurses5-dev libssl-dev python3-distutils rsync unzip zlib1g-dev
      file wget cmake ninja-build libelf-dev libtool m4 intltool pkg-config
      subversion ccache qemu-utils bzip2 xz-utils patch perl python3
注意：请勿使用 root 运行。
